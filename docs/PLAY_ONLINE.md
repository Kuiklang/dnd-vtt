# คู่มือเล่น Arcane Table กับเพื่อน (ฟรี)

เว็บรันบนคอมของ DM เครื่องเดียว เพื่อนเปิดผ่านเบราว์เซอร์ ไม่ต้องเช่า server และไม่ต้องจ่ายค่า API

---

## 1. ติดตั้งครั้งแรก (Windows)

1. **โหลดโค้ด:** เปิด https://github.com/Kuiklang/dnd-vtt → ปุ่มสีเขียว **Code** → **Download ZIP**
   แตก ZIP ไว้ในโฟลเดอร์ที่จำง่าย เช่น `C:\ArcaneTable`
   (ถ้าใช้ git อยู่แล้ว: `git clone https://github.com/Kuiklang/dnd-vtt.git`)
2. **ดับเบิลคลิก `setup-windows.bat`**
   - ถ้ายังไม่มี Node.js สคริปต์จะติดตั้งให้ (ผ่าน winget) แล้วบอกให้เปิด `setup-windows.bat` อีกครั้ง
   - ครั้งแรกใช้เวลาหลายนาที (โหลดส่วนประกอบ + สร้างเว็บ)
   - จบแล้วจะขึ้นว่า `Setup finished!`
3. **(แนะนำ) ติดตั้ง Claude Code** เพื่อใช้ AI ผู้ช่วย DM และอ่าน character sheet จาก PDF/รูป แบบฟรีตามแพ็กเกจ Claude ของคุณ
   - เปิด PowerShell แล้วพิมพ์ `irm https://claude.ai/install.ps1 | iex`
     (หรือถ้ามี Node แล้ว: `npm install -g @anthropic-ai/claude-code`)
   - พิมพ์ `claude` หนึ่งครั้งแล้วล็อกอินบัญชี Claude ของคุณ จากนั้นปิดได้เลย
   - ถ้าไม่ติดตั้ง เว็บยังเล่นได้ครบ แค่ปุ่ม AI จะบอกว่ายังไม่ได้ตั้งค่า

> Mac / Linux: ติดตั้ง Node.js 22+ และ pnpm แล้วรัน `pnpm setup:play` ครั้งแรก และ `pnpm play` ทุกครั้งที่จะเล่น

## 2. เริ่มเล่นทุกครั้ง

ดับเบิลคลิก **`start-windows.bat`** → เบราว์เซอร์เปิด http://localhost:3001 เอง

- เปิดหน้าต่างดำนั้นทิ้งไว้ตลอดที่เล่น ปิดหน้าต่าง = ปิดเกม
- ข้อมูลทั้งหมด (แคมเปญ, ตัวละคร, แผนที่, เพลง) เก็บในโฟลเดอร์ `data` ข้างๆ ไฟล์ .bat — **สำรองโฟลเดอร์นี้** ถ้าจะย้ายเครื่อง
- ไม่ต้องติดตั้งฐานข้อมูลเอง โปรแกรมมีฐานข้อมูลในตัว (เปิดให้เฉพาะคอมเครื่องนี้เข้าถึง)
- Windows อาจถามเรื่อง Firewall ตอนเปิดครั้งแรก: ถ้าจะให้เพื่อนในบ้าน/Wi-Fi เดียวกันเข้า ให้กด **Allow** สำหรับ Private network

## 3. ชวนเพื่อนเข้าเล่น

### ก. เพื่อนอยู่คนละบ้าน (ผ่านอินเทอร์เน็ต) — วิธีที่แนะนำ

1. เปิด `start-windows.bat` ค้างไว้
2. ดับเบิลคลิก **`play-online-windows.bat`** (ครั้งแรกจะติดตั้ง `cloudflared` ของ Cloudflare ให้ ฟรี แล้วให้เปิดไฟล์นี้อีกครั้ง)
3. มองหาบรรทัดที่มีลิงก์ `https://xxxx-xxxx.trycloudflare.com` → ส่งลิงก์นี้ให้เพื่อน
4. ในเว็บ: สร้างแคมเปญ → หน้า Lobby → **Invite** → คัดลอกลิงก์เชิญ (ลิงก์จะเป็นโดเมน trycloudflare ให้เอง ถ้าคุณเปิดเว็บผ่านลิงก์นั้น)
   เพื่อนเปิดลิงก์ → สมัครหรือเข้าแบบ Guest → เข้าห้องได้เลย

ข้อควรรู้:
- ลิงก์ trycloudflare **เปลี่ยนทุกครั้ง** ที่เปิด `play-online-windows.bat` ใหม่ (ฟรีและไม่ต้องสมัคร แต่ไม่มีการรับประกันความเสถียร)
- ปิดหน้าต่างนี้ = หยุดแชร์ (เกมในเครื่องยังเปิดอยู่)
- ลิงก์นี้เป็น https จึงใช้ **voice chat** ได้ (เบราว์เซอร์อนุญาตไมค์เฉพาะ https หรือ localhost)
- ถ้าอยากได้ลิงก์ถาวร: สมัคร Cloudflare ฟรีแล้วทำ Named Tunnel กับโดเมนของตัวเอง หรือใช้ Tailscale (ด้านล่าง)

### ข. ทางเลือก: Tailscale (ลิงก์คงที่, ปลอดภัย)

- **เฉพาะเพื่อนที่ชวน:** ทุกคนติดตั้ง [Tailscale](https://tailscale.com) (ฟรีสำหรับใช้ส่วนตัว) แล้ว DM แชร์เครื่องให้เพื่อน
  เพื่อนเปิด `http://ชื่อเครื่อง:3001` — แต่เป็น http จึง **ใช้ไมค์ไม่ได้** ให้คุยผ่าน Discord แทน หรือใช้ Funnel
- **Tailscale Funnel (https):** บนเครื่อง DM รัน `tailscale funnel 3001` → ได้ลิงก์ `https://ชื่อเครื่อง.xxx.ts.net` ที่ใช้ voice ได้

### ค. เพื่อนอยู่ Wi-Fi เดียวกัน

หน้าต่าง `start-windows.bat` จะแสดง `Friends on the same Wi-Fi: http://192.168.x.x:3001` → ให้เพื่อนเปิดลิงก์นั้น
(voice chat ใช้ไม่ได้บนลิงก์ http นี้ ถ้าจะใช้เสียงให้ใช้ลิงก์ trycloudflare แทน)

## 4. Voice chat

- ในหน้าโต๊ะ แผงซ้าย **คุยด้วยเสียง → เข้าห้องเสียง** แล้วอนุญาตไมค์
- เสียงวิ่งตรงระหว่างเครื่อง (ไม่ผ่าน server) จึงเหมาะกับวงไม่เกิน ~8 คน
- ถ้าเพื่อนบางคนขึ้น "เชื่อมต่อไม่ได้" (มักเป็นเน็ตมือถือ/เน็ตบริษัท) ต้องใช้ TURN server:
  ใส่ `VOICE_ICE_SERVERS` ใน `apps\server\.env` (ดูตัวอย่างในไฟล์) หรือใช้ Discord คุยแทนได้

## 5. ตั้งค่า (ไฟล์ `apps\server\.env`)

| ค่า | ความหมาย |
| --- | --- |
| `PORT=3001` | พอร์ตของเว็บ (ถ้าเปลี่ยน ต้องแก้ใน `play-online-windows.bat` ด้วย) |
| `AI_PROVIDER=claude-code` | ใช้ Claude Code ในเครื่องนี้ (ฟรี) · `off` = ปิด AI |
| `CLAUDE_CODE_PATH` | ใส่ path เต็มของ `claude` ถ้าโปรแกรมหาไม่เจอ |
| `AI_PER_HOUR=30` | จำนวนครั้งที่ DM ถาม AI ได้ต่อชั่วโมง |
| `VOICE_ICE_SERVERS` | TURN/STUN สำหรับ voice (เว้นว่าง = ใช้ค่าฟรีมาตรฐาน) |

แก้แล้วปิด-เปิด `start-windows.bat` ใหม่

## 6. แก้ปัญหา

| อาการ | วิธีแก้ |
| --- | --- |
| `Port 3001 is already in use` | เกมเปิดอยู่แล้วในอีกหน้าต่าง หรือมีโปรแกรมอื่นใช้พอร์ต → ปิดหน้าต่างเก่า หรือเปลี่ยน `PORT` |
| `The website isn't built yet` | เปิด `setup-windows.bat` ก่อน |
| AI ขึ้นว่า Claude Code ไม่ได้ติดตั้ง/ไม่ได้ล็อกอิน | ทำข้อ 1.3 แล้วเปิด `start-windows.bat` ใหม่ |
| เพื่อนเข้าลิงก์ trycloudflare ไม่ได้ | เช็กว่า `start-windows.bat` ยังเปิดอยู่ และส่งลิงก์ล่าสุด (เปลี่ยนทุกครั้ง) |
| อัปเดตเวอร์ชันใหม่ | โหลด ZIP ใหม่ทับ (เก็บโฟลเดอร์ `data` และ `apps\server\.env` ไว้) แล้วเปิด `setup-windows.bat` อีกครั้ง |

## ความปลอดภัย (สั้นๆ)

- เพื่อนเห็นเฉพาะสิ่งที่ DM อนุญาต: token ที่ซ่อน/อยู่หลังกำแพง/ในหมอก, DM notes, journal ลับ, คำตอบ AI ไม่ถูกส่งไปที่เบราว์เซอร์ของผู้เล่นเลย
- ฐานข้อมูลเปิดให้เฉพาะคอมเครื่องนี้; ลิงก์ trycloudflare เปิดแค่ตัวเว็บ
- ใครได้ลิงก์ก็สมัครบัญชีได้ แต่เข้าแคมเปญได้เฉพาะคนที่มีลิงก์เชิญ — ยกเลิกลิงก์เชิญได้ในหน้า Lobby
